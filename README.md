# Smart Task Manager REST API

A backend Task Manager application built using Java and Spring Boot.

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Postman

## Current Features

- Create a task
- Get all tasks
- Get task by ID
- Update a task
- Delete a task
- MySQL database integration
- REST API architecture
